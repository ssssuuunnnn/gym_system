# ADR 0014：收支報表（現金制）

- **狀態**：已採納
- **日期**：2026-11-02
- **決策者**：Sunkuo
- **前提**：[ADR 0007 分店](0007-branches.md)、[ADR 0008 後台帳號與權限](0008-staff-permissions.md)、[ADR 0010 優惠券](0010-coupons.md)

## 背景

店家想在系統裡看每個月賺多少錢。系統已經有方案銷售（`purchases`，含付款狀態、付款方式、優惠折抵）與教練鐘點撥款（`coach_payouts`），但房租、水電、耗材、場租收入等不在系統裡；收入也沒有記錄屬於哪間分店，無法看分店的收支。

## 決策

### 1. 現金制

收入與支出都以「錢實際進出」的時間計入（R57）：

- **收入**：已付款購買紀錄的實收金額（`amount`，已扣掉優惠），日期＝`paid_at` 換算的店家當地日期。待付款、已取消不算；體驗券兌換的 0 元紀錄只計筆數。
- **支出**：已撥款的教練鐘點（`coach_payouts.status = paid`），日期＝`paid_at`。已結算但還沒撥款的不算。
- **手動帳目**：店家自己輸入的收入／支出，日期由店家填。

「上完課才算收入」（權責制）和預收款（已收錢還沒上的課）放到第二期。

### 2. 收入與鐘點歸屬分店

- `purchases.branch_id`（必填，R58）：團體課程方案 → 課程的分店；只限一間分店的方案 → 那間；其他 → 後台登錄時選的分店，會員自己購買時用會員在預約頁選的分店，都沒有就用預設分店。`db/session._fill_branch_id` 也幫沒指定的新購買紀錄補上（體驗券兌換、詢問轉會員等呼叫端不用改）。舊資料由 migration 依同樣規則回填。
- `coach_payout_items.branch_id`：結算時記下每一堂在哪間分店（預約的分店）。鐘點支出依明細分攤到分店。舊明細回填：團體課 → 課程分店；私人課 → 找同教練、同日同時段的預約；找不到用預設分店。
- 手動帳目的分店可留空＝全店共同（例如總部會計費）。看單一分店的報表時不計入，但會另外列出「全店共同」的金額，避免誤以為分店淨額就是全店淨額。

### 3. 手動帳目與分類

- `accounting_categories`（租戶／RLS）：`kind` 收入／支出、`name`（同一類型內不重複）、`is_active`、`sort_order`。第一次讀取時建立預設分類（收入：場租收入、其他收入；支出：租金、水電瓦斯、人事薪資、耗材用品、行銷廣告、設備維修、其他支出）。用過的分類不能刪，只能停用。
- `accounting_entries`（租戶／RLS）：`kind`、`category_id`、`entry_date`、`amount`（> 0）、`payment_method`（現金／轉帳／刷卡／其他）、`branch_id`（可空）、`note`、建立／修改者名稱與時間。刪除是軟刪除（`deleted_at`、`deleted_by_name`），報表不計，列表可查看已刪除的帳目（R59）。
- 收據照片第一期不做：`/media` 是公開的靜態檔案，收據不適合放在那裡，要等有需要登入才能讀的檔案再做。

### 4. 報表

`routers/accounting.py`（權限 `accounting`）：

- `GET /accounting/report?start&end&branch_id`：期間（最長 1 年）的收入、支出、淨額。收入分「方案銷售」（依商品類別：團體課程／課程／用品）與手動收入分類，另外列付款方式分布與優惠折抵總額；支出分教練鐘點與手動支出分類。選分店時附上全店共同的收入／支出金額。
- `GET /accounting/trend?months&branch_id`：近 N 個月（≤ 24）每月的收入、支出、淨額。
- `GET /accounting/transactions?start&end&branch_id&kind`：期間內每一筆的明細（銷售、鐘點撥款、手動帳目合在一起），前端做 CSV 匯出。
- 分類與手動帳目的 CRUD：`/accounting/categories`、`/accounting/entries`。

### 5. 權限

新增功能代碼 `accounting`「收支報表」（含敏感資料），加入「會計」範本；側欄新分類「財務」。

## 結果

- 店家每月在同一頁看到收入、支出與淨額，可依分店拆開，並匯出明細給會計。
- 購買紀錄多了分店；後台登錄購買要選分店（只有一間時自動帶入）。
- 已付款訂單的退款流程仍未定義：目前退款只能用手動支出記一筆。

# ADR 0015：收支報表第二期（權責制、預收款、關帳、收據照片）

- **狀態**：已採納
- **日期**：2026-11-02
- **決策者**：Sunkuo
- **前提**：[ADR 0014 收支報表](0014-accounting-report.md)

## 背景

第一期的收支報表是現金制：會員一次買 20 堂，收款那個月收入很高，之後幾個月上課卻沒有收入，看不出每個月真正賺多少。店家也想知道「已收錢、還沒上課」的金額（預收款），會計結帳後不希望帳目再被改動，手動帳目也需要附收據。

## 決策

### 1. 權責制：上完課才算收入（R61）

報表多一個「計算方式」：現金制（第一期）／權責制。權責制時：

- **課程類方案**（團體課程、課程）：每堂價值＝實收金額 ÷ 購買總堂數。從 `hour_ledger` 算出每筆預約的淨扣堂數（扣抵 − 退回），在**上課日**（且上課日已到）認列「淨扣堂數 × 每堂價值」；晚取消沒退堂的照樣認列。手動調整扣掉的堂數在調整當天認列；手動補的堂數沒有價值。同一筆購買認列的總額不超過實收金額。分店＝上課的分店。
- **用品**：收款日認列（同現金制），分店＝購買的分店。
- **人員費用**：已結算（含已撥款）鐘點明細依上課日計入；還沒結算的月份不計（報表會提示）。
- **手動帳目**：同現金制，依帳目日期。

計算都在 `services/accounting.py`，不新增資料表：資料來源是既有的 `purchases`、`hour_ledger`、`reservations`、`coach_payout_items`。

### 2. 預收款（R62）

某一天的預收款＝已收款的課程類方案實收金額 − 截至那天已認列的金額，依方案列出筆數、未上堂數與金額；分店以購買的分店計。`GET /accounting/deferred?as_of&branch_id`。

### 3. 關帳（R63）

`accounting_closes`（租戶／RLS）：`period`（該月 1 日，每家每月一列）、`is_closed`、關帳／重新開帳的人與時間、`snapshot`（關帳當下該月現金制與權責制的收入、支出、淨額，以及月底預收款）。

- 只能關已結束的月份（店家當地時間）。
- 關帳後，日期在該月的手動帳目不能新增、修改、刪除，也不能換收據；把帳目日期改到已關帳的月份也不行。
- 方案銷售與鐘點撥款的日期都是「操作當下」，不會落在已結束的月份，所以不需要另外鎖。
- 重新開帳只有主要管理者可以，紀錄留在同一列（`reopened_at`、`reopened_by_name`）；再關帳時重新拍快照。

### 4. 收據照片（R64）

- `accounting_entries.receipt_path`：檔案存在**非公開**資料夾 `PRIVATE_MEDIA_DIR/<subdomain>/receipts/<uuid>.<ext>`（`core/media.save_private_media`），不在對外的 `/media` 底下；只能透過 `GET /accounting/entries/{id}/receipt`（需要收支報表權限）讀取，回應帶 `Cache-Control: private, no-store`、`X-Content-Type-Options: nosniff` 與下載用的 `Content-Disposition`。
- 接受 jpg、png、pdf，最大 5MB，同時檢查 Content-Type 與檔頭。每筆帳目一張，可以替換或移除；帳目刪除後收據仍可查看。
- docker compose 新增 volume `private_media`（正式環境跟著 Lightsail 每日快照備份）。

## 結果

- 店家可以切換現金制／權責制，看出每月實際上課帶來的收入；預收款讓店家知道還欠會員多少堂課。
- 會計可以按月關帳，關帳後的數字有快照可對照。
- 權責制的人員費用只含已結算的月份；未結算月份的收入已認列但費用還沒進來，報表會提示。

Standard Ant Design button — use for any primary action, form submit, or toolbar action.

```jsx
<Button type="primary">建立會員</Button>
<Button>取消</Button>
<Button type="dashed" icon={<i className="ri-add-line"/>}>新增方案</Button>
<Button type="link">查看全部</Button>
<Button danger>刪除</Button>
```

Variants: `type` (default/primary/dashed/text/link), `size` (large/middle/small), `danger`, `disabled`, `loading`, `block`, `icon`.
